## Robotic!

Ever since 7th grade, I’ve always studied with my older classmates (because we didn’t take robotics in 7th grade).
When I started 8th grade, I was so happy to finally be able to take this class, which turned out to be my favorite.
And I got the chance to go to Malaysia I was so HAPPY!!

## Practicing before malay (very tiring)

We’ve got about two weeks. SORRY, I FORGOT, so my partner and I have to practise after school, and we need to understand
the robot and how it works (because) I accidentally and stupidly deleted our ONLY learning resource, as a result of which we struggled
for about a week, and a week before the competition we even had to skip classes just to practise using this robot, and I
missed a lot of lessons at the time, but I’m glad we managed to sort it out x/

We had two things to sort out: configuring the wheels or motors, because my teacher said the factory-made wheels weren’t perfect. 
There’s bound to be a slight difference. YES, we all know robotics components aren’t always perfect; I felt like I was taking a gamble on everything. Then there’s the software: I’M GLAD WE’RE USING a SCRATCH-BASED programming language for this competition (I LOVE SCRATCH). 
And we were given some ready-made code to study, which was a HUGE help in this regard. We hadn’t done any practice for this until we arrived in Malaysia ;)
